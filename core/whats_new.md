## I do the work myself now
Ask for research, a chart, a file or some code and I do it right here in the channel: you see what I'm looking at as I go, the files arrive here, then I answer. No more separate sandbox threads, and the chat keeps going while I work.
How to use: "compare the three cheapest 4K monitors and make a table", "chart how many messages each of us sent this week"

## Big jobs run as workflows
For a job with many parts, I write a plan in a thread of its own and wait for you to press Approve (or Edit, or Cancel). Then I work through the steps, check the result, and tell you here when it's done. Write in the thread to change something while I work, or say "stop".
How to use: ask for something big, like "research the five best-reviewed budget laptops and write a report", or use /task

## I remember what you tell me
Tell me something worth keeping and I save it, and now I actually use it: your preferences and details come with every message you send me.
How to use: "remember I prefer metric units". To remove it: "forget that I prefer metric units", or "forget everything about me"

## I learn skills
When a job takes several steps that will come up again, I save how I did it as a skill for this server and use it next time, so it's faster and more steady. Anyone can see, edit or undo them.
How to use: "save that as a skill", or /skills list

## I ask before I guess
If a guess would waste the work, I ask you first, with buttons for the likely answers, "Answer…" to type your own, and "You decide". No answer in 2 minutes and I carry on with my best guess.
How to use: just ask as usual; answer with a button, or with Discord's Reply on my question

## The server's workspace
Every server has its own workspace where I run code and keep files; ask me to keep something and it stays in shared/ for later.
How to use: /workspace status, /workspace progress on to watch my commands live, /workspace reset to start clean (status and reset need Manage Server)
