# Security Policy

## Supported versions

Security fixes are made on the default branch and included in the next release.
Only the latest release is supported.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's
[private vulnerability reporting form](https://github.com/dgowing95/DiscordChatBot/security/advisories/new)
so the report and any follow-up remain confidential.

Include affected versions, reproduction steps, the likely impact, and any
suggested mitigation. You should receive an acknowledgement within seven days.
Please allow time for a fix and coordinated disclosure before publishing details.
